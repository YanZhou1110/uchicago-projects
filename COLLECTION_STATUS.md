# Collection Status

This collection contains 24 top-level project/coursework directories: seven initially organized code collections, sixteen additional code collections, and one HERE contribution overview. Related assignments are grouped together and are not represented as 24 independent research projects.

- GraphRAG and a local calendar/search assistant.
- SEC filing question answering, complementary to risk classification.
- Yoga recognition, YOLO-World, research-paper RAG, CIFAR representations, LoRA, imitation learning, CNN and object detection coursework.
- Chicago 311, employment/compensation and education/safety visualization.
- Tabular machine learning submissions and earlier news NLP assignments.
- A high-level HERE capstone contribution overview.

## Material not distributed

Client/team source code and raw images/GPS trajectories for HERE are not part of this release. Verizon consulting materials remain pending a disclosure-scope review. The data visualization final-project folder contains assignment/data materials, but a completed implementation was not identified during this local inventory, so no finished final project is claimed. Lecture notebooks, duplicate copies, raw datasets, private calendars, user uploads, credentials and model weights are omitted.

This is an inventory of the local material reviewed for this release, not a guarantee that every historical chat attachment or later project version has been recovered.

## Validation

The latest addition contains 23 notebooks with 316 code cells and 19 standalone Python files. Notebook JSON and Python/IPython syntax were checked, outputs and attachments cleared, and selected personal-path/credential patterns scanned. No models were trained and no data-dependent or API-backed evaluation was executed. README dependency lists are inventories, not verified environment lockfiles.
