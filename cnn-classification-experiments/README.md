# CNN Classification Experiments

Selected completed CNN coursework for digit and clothing classification, with a companion interpretation notebook.

## Contents

- `mnist_fashionmnist.ipynb`
- `cnn_interpretations.ipynb`

## Setup and run

Use a project-specific environment and start from this directory:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab
```

Dependencies are an inventory, not a tested lockfile. Some notebooks target Colab, GPU runtimes or additional optional packages. Inspect configuration and data paths before running. File paths formerly pointing to a personal computer or Drive were replaced with local `data/` paths.

## Data and results

Inspect each notebook for its dataset download, experimental setup and environment requirements. Related notebook versions are retained as separate analyses, not counted as distinct portfolio achievements. Historical narrative metrics need verification against fresh execution.

Historical narrative results in the original notebook have not been independently reproduced; no new performance claim is made by this upload.
