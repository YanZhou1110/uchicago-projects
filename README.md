## Reading the collection

Code collections include English overviews, source code or notebooks, dependency inventories, data setup notes and limitations. The HERE page is an overview rather than a source-code release. These are organized course materials, not independently reproduced benchmarks. Refer to each project for evaluation caveats and data requirements.

Raw datasets, private course/cloud locations, credentials, model weights and cached notebook outputs are excluded from this preparation. Obtain data through authorized original sources. The HERE capstone has a public contribution overview only; client/team source code and driving data remain excluded.

Existing repository files are preserved when this collection is added. The earlier assignment notebook can remain as a historical version; the local News RAG submission in this collection is a different version.
