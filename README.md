## Reading the collection

Each project includes an English overview, source code or notebooks, dependency inventory, data setup notes and limitations. These are organized course materials, not independently reproduced benchmarks. Refer to each project for evaluation caveats and data requirements.

Raw datasets, private course/cloud locations, credentials, model weights and cached notebook outputs are excluded from this preparation. Obtain data through authorized original sources. Client/team trajectory-reconstruction materials are held outside this collection for a separate publication decision.

Existing repository files are preserved when this collection is added. The earlier assignment notebook can remain as a historical version; the local News RAG submission in this collection is a different version.
